Компоненти програмної інженерії: Лабораторна робота 2

Дослідження базових UI елементів та їх призначення.

1. Radiobutton (Радіокнопка)

Призначення: Вибір лише одного варіанту з декількох запропонованих. Якщо обрано інший пункт, попередній вибір скасовується.

2. Checkbox (Прапорець)

Призначення: Дозволяє користувачу вибрати один, декілька або жодного варіанту з наданого списку. Також використовується для увімкнення/вимкнення певних опцій.

3. Text input (Текстове поле)

Призначення: Елемент для введення короткого, однорядкового тексту користувачем (наприклад, імені, пошукового запиту тощо).

4. Tabs (Вкладки)

Призначення: Дозволяють організувати контент у розділи, перемикання між якими відбувається без перезавантаження сторінки. Це допомагає зекономити місце на екрані.

Ви зараз переглядаєте контент другої вкладки.

5. Button (Кнопка)

Призначення: Ініціація певної дії після натискання: відправка форми, відкриття вікна, підтвердження вибору тощо.

6. Text label (Текстова мітка)

Призначення: Пояснює користувачеві, які дані очікуються. Якщо мітка правильно пов'язана з полем (через атрибут `for`), натискання на неї автоматично переносить фокус на відповідний елемент.

7. Link (Посилання)

Офіційний сайт КПІ

Призначення: Забезпечення навігації. Перенаправляє користувача на іншу сторінку, зовнішній ресурс або певну частину поточної веб-сторінки.

8. Tooltip (Підказка)

Наведіть курсор на це підкреслене словоЦе спливаюча підказка (Tooltip), щоб побачити пояснення.

Призначення: Надання додаткової контекстної інформації при наведенні курсору на елемент. Дозволяє не перевантажувати основний інтерфейс зайвим текстом.

9. Dropdown list (Випадний список)

Призначення: Компактне відображення списку опцій. Дозволяє користувачеві вибрати одне значення з багатьох, не займаючи багато місця на сторінці.
